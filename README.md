# Midnight Assist 1.4.0 - Fabric & Quilt 26.3

Aim assist for Minecraft that makes aiming with a gamepad or touch controls feel natural and fair.

## This branch

| | |
| --- | --- |
| Loader | Fabric / Quilt |
| Minecraft | 26.3 |
| Mod version | 1.4.0 |
| Mod id | midnight_assist |
| Java | Java 25 |

Quilt is supported by this same build; no separate Quilt jar is needed.

## Requirements

- Fabric Loader 0.19.3
- Fabric API 0.160.6+26.3
- Fabric Language Kotlin 1.14.1+kotlin.2.4.20
- Cloth Config 26.3.158
- Mod Menu 21.0.0-beta.1

## Building

    ./gradlew build

The jar is written to build/libs/midnight-assist-1.4.0.jar.
