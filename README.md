# Midnight Assist 1.4.0 - NeoForge 26.1

Aim assist for Minecraft that makes aiming with a gamepad or touch controls feel natural and fair.

## This branch

| | |
| --- | --- |
| Loader | NeoForge |
| Minecraft | 26.1, 26.1.1, 26.1.2 |
| Mod version | 1.4.0 |
| Mod id | midnight_assist |
| Java | Java 25 |

Install on the NeoForge loader for the Minecraft version above.

## Requirements

- NeoForge 26.1.2.122
- Cloth Config 26.1.154

## Building

    ./gradlew build

The jar is written to build/libs/midnight-assist-1.4.0.jar.
