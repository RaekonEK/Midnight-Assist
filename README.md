# Midnight Assist 1.4.0 - Fabric & Quilt 1.17

Aim assist for Minecraft that makes aiming with a gamepad or touch controls feel natural and fair.

## This branch

| | |
| --- | --- |
| Loader | Fabric / Quilt |
| Minecraft | 1.17, 1.17.1 |
| Mod version | 1.4.0 |
| Mod id | midnight_assist |
| Java | Java 16/17 |

Quilt is supported by this same build; no separate Quilt jar is needed.

## Requirements

- Fabric Loader 0.16.14
- Fabric API 0.46.1+1.17
- Fabric Language Kotlin 1.13.9+kotlin.2.3.10
- Cloth Config 5.3.63
- Mod Menu 2.1.2

## Building

    ./gradlew build

The jar is written to build/libs/midnight-assist-1.4.0.jar.
